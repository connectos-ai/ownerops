# OwnerOps Channel Canvas Template

Copy this into the canvas for `#ownerops-inbox` or a team operations channel.

## Purpose

This channel captures work, decisions, blocked items, and follow-up so important work does not disappear in chat.

## How Tasks Enter

Paste new work using this format:

```text
TASK:
OUTCOME:
OWNER:
DUE:
PRIORITY:
SOURCE:
STATUS:
NEXT ACTION:
```

## Status Legend

- Eyes: acknowledged
- Raised hand: claimed
- Blue circle: in progress
- Pause: waiting
- Warning: blocked
- Crown: owner decision
- Check mark: done
- No entry: cancelled

## Weekly Rhythm

- Monday: set priorities.
- Daily: review inbox, today, waiting, blocked, and owner decisions.
- Friday: close completed work and carry forward unfinished work.

## Team Rules

- Every task has one accountable owner or is marked Unassigned.
- Updates stay in the task thread.
- Blocked work must include why it is blocked and who can unblock it.
- Owner decisions should state the smallest decision needed.
